# Amazon Q for Visual Studio Code

Amazon Q for VS Code is a generative AI coding companion that helps you build applications faster and more securely within Visual Studio Code.

## Features

### Code Generation and Assistance
- **Chat with Amazon Q**: Ask questions, get code examples, and receive guidance on software development topics
- **Code Suggestions**: Receive inline code suggestions as you type
- **Code Transformation**: Convert code between programming languages, refactor existing code, and more

### Security and Code Quality
- **Q Review**: Scan your code for security vulnerabilities and quality issues
- **Q Fix**: Automatically fix identified issues with one click

### Application Modernization
- **Java Application Transformation**: Upgrade legacy Java applications to newer versions

## Getting Started

1. Install the [Amazon Q extension](https://marketplace.visualstudio.com/items?itemName=AmazonWebServices.amazon-q-vscode) from the VS Code marketplace
2. Sign in with your AWS Builder ID, AWS IAM Identity Center, or AWS IAM credentials
3. Start chatting with Amazon Q using the chat panel or get inline suggestions as you code
